# 📖 Le Carnet des Gagnants

> Écrire. Progresser. Se souvenir. Grandir.

## Présentation

Le Carnet des Gagnants est une application de développement personnel permettant de conserver ses réussites, suivre sa progression et cultiver la gratitude.

L'objectif est de créer un compagnon numérique qui accompagne son utilisateur dans son évolution personnelle.

## Philosophie

Le Carnet des Gagnants est conçu autour de quatre idées :

- Écrire
- Progresser
- Se souvenir
- Grandir

Chaque fonctionnalité doit respecter cette philosophie.
